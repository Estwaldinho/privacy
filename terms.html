Условия использования

Приложение «Ассистент для часов» (ru.watch.assistant). Дата последнего обновления: 28 октября 2026 г.

1. Назначение

Приложение предназначено для личного использования владельцем устройства. Оно предоставляется «как есть», без гарантий бесперебойной работы и без гарантий точности ответов, распознавания речи или созданных напоминаний.

2. Использование сторонних сервисов

Для работы приложение обращается к сторонним сервисам:

  • GigaChat — распознавание речи и формирование ответов;
  • Google Tasks и Google Calendar — создание напоминаний, задач и событий (только после авторизации владельца);
  • поисковые сервисы — при явном запросе информации из интернета.

Используя приложение, вы соглашаетесь с условиями этих сервисов. Приложение не является их представителем и не отвечает за их доступность.

3. Ответственность пользователя

  • Доступ к аккаунту Google предоставляется владельцем добровольно; доступ можно отозвать в любой момент на myaccount.google.com/permissions.
  • Проверка важных данных (напоминаний, событий, будильников) остаётся за пользователем.
  • Приложение не предназначено для управления системами безопасности, медицинскими приборами или иными критичными устройствами.

4. Ограничение ответственности

Автор приложения не несёт ответственности за любые прямые или косвенные последствия использования приложения, включая пропущенные напоминания, неточные ответы распознавания речи или действия, выполненные по голосовой команде.

5. Изменения

Условия могут обновляться; актуальная версия всегда доступна на этой странице.
