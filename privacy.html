Политика конфиденциальности

Приложение «Ассистент для часов» (ru.watch.assistant) — личный некоммерческий проект. Дата последнего обновления: 28 октября 2026 г.

1. Кто обрабатывает данные

Приложение разработано и используется частным лицом для личных нужд. Оно не является коммерческим сервисом, не имеет серверной инфраструктуры и не собирает данные пользователей для каких-либо посторонних целей.

2. Какие данные обрабатываются

  • Голос. Запись с микрофона часов передаётся по Bluetooth на телефон владельца. Распознавание выполняется либо локально на телефоне (офлайн-модель Vosk), либо через API GigaChat, если включён облачный режим.
  • Текст запросов и ответов. Отправляется в GigaChat для формирования ответа. История диалога хранится только в оперативной памяти телефона и очищается при перезапуске.
  • Данные Google Tasks и Google Calendar. Используются только после явной авторизации владельца аккаунта — для создания напоминаний, задач и событий.
  • Настройки и токены доступа. Хранятся локально в защищённом хранилище приложения на телефоне владельца.

Приложение не собирает аналитику, не показывает рекламу, не создаёт профили и не считывает контакты, местоположение или иные данные, кроме перечисленных выше.

3. Где хранятся данные

Все данные хранятся только на устройстве владельца (телефон и сопряжённые часы). Собственных серверов у проекта нет; данные не выгружаются в облако проекта.

4. Передача третьим лицам

Данные передаются исключительно обработчикам, без которых работа невозможна:

  • GigaChat — распознавание речи и формирование ответов;
  • Google — создание и чтение задач и событий календаря (по желанию владельца);
  • поисковые сервисы — при явном запросе информации из интернета.

Данные не продаются, не передаются рекламным сетям и не используются для профилирования.

5. Использование данных Google

Приложение запрашивает доступ к Google Tasks и Google Calendar только для того, чтобы создавать напоминания, задачи и события по просьбе владельца и показывать их список. Приложение:

  • не передаёт данные Google третьим лицам;
  • не использует их для рекламы или аналитики;
  • не читает данные, не связанные с напоминаниями и календарём.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

6. Удаление данных и отзыв доступа

Отозвать доступ приложения к аккаунту Google можно на странице myaccount.google.com/permissions. Локальные данные (токены, настройки, история) удаляются вместе с приложением.
